# 入湖：生成数据入湖申请 Excel 文档

## 目标

基于 `skills/入湖/数据入湖申请表模版.xlsx`，根据用户提供的源库信息和同步表清单，生成完整的数据入湖申请 Excel 文档。输出 Excel 包含三个 Sheet：

1. **数据入湖申请表单**：主申请表，含基础信息、来源数据库信息、同步表清单、授权信息等
2. **填写说明**：申请表各字段的填写规范与审批流程说明
3. **表结构说明模板**：每张待同步表的字段级 DDL 说明

## 触发方式

- `/入湖`
- `/入湖 <路径或需求描述>`
- "生成入湖申请表"
- "数据入湖 Excel"
- "填写入湖申请"
- "帮我生成一份入湖申请表"

## 模版说明

模版文件位于 `skills/入湖/数据入湖申请表模版.xlsx`，包含三个 Sheet：

### Sheet 1：数据入湖申请表单

| 区域 | 行 | 内容 |
|---|---|---|
| 标题 | Row 1 | 数据入湖申请表（深蓝底白字，16pt 加粗） |
| 一、基础申请信息 | Row 3-5 | 项目组、产品经理、技术经理、申请日期 |
| 三、来源数据库信息【必填】 | Row 8-13 | 数据库类型、环境、地址、端口、库名、Schema、账号、源库技术经理 |
| 四、同步表基本信息 | Row 16-26 | 表清单（序号、表名、中文名、规模、增量、DDL、主键、物理删除、同步类型、频率、增量条件、全量初始化、全量原因、更新逻辑） |
| 五、其他信息 | Row 29-31 | 期望完成时间、申请事由/变更说明 |
| 六、授权需求和抽数频率及时间 | Row 34-36 | 授权项目名称、授权应用、授权日期、抽数频率、抽数时间点 |

### Sheet 2：填写说明

包含适用范围、填写规范（5 条）、审批流程（3 步）的说明文本。

### Sheet 3：表结构说明模板

四列结构：`表名 | 字段名 | 字段类型 | 中文描述`，每张表按字段逐行列出。

## 固定工作流

### 第一步：确认申请元信息

在生成 Excel 之前，必须先向用户确认以下必填信息（如果用户没有提供）：

有些是默认项：所属项目组名称 One蛇口

产品经理：刘琨

技术经理：周佳佳

申请日期：今天日期

源库技术经理：周佳佳

| 必填信息 | 说明 | 示例 |
|---|---|---|
| 项目组 | 所属项目组名称 | `One蛇口 |
| 产品经理 | 产品负责人 | `刘琨` |
| 技术经理 | 技术负责人 | `周佳佳`` |
| 申请日期 | 申请提交日期 | `2026.07.22` |
| 数据库类型 | MySQL / Oracle / PostgreSQL 等 | `MySQL` |
| 数据库环境 | 生产 / 测试 / 预发布 | `生产` |
| 数据库地址 | 源库 IP 或域名 | `100.102.1.47` |
| 端口 | 数据库端口 | `3308` |
| 数据库名 | 业务库名 | `商城` |
| Schema | 数据库 Schema | `cmp_mall` |
| 访问账号 | 只读访问账号 | `cmpmall` |
| 源库技术经理 | 源库侧技术负责人 | `周佳佳` |

> 📌 如果用户未提供完整信息，逐项询问确认后再生成。不要让用户猜，应给出合理默认值供确认。

### 第二步：确认同步表清单

针对每张待同步的表，逐表确认以下信息：

| 必填字段 | 说明 |
|---|---|
| 表名 | 源表名 |
| 表中文名 | 业务中文名称 |
| 表当前规模 | 记录数、空间大小 |
| 每年增量规模 | 预估年增量 |
| 表结构说明/DDL | 完整 CREATE TABLE 语句 |
| 主键/唯一键说明 | 主键字段 |
| 是否有物理删除 | 是/否 |
| 同步类型 | 全量/增量（优先增量） |
| 同步频率 | 实时/小时级/每日一次/每周一次 |
| 增量同步条件 | 如更新时间字段、主键ID范围等 |
| 初次执行是否需要全量初始化 | 需要/不需要 |
| 如需全量同步请说明原因 | 原则上应尽量增量同步 |
| 源表更新逻辑 | 实时更新/定时更新(更新时间) |

> 📌 同步类型优先选择「增量同步」；全量同步需在「全量同步必要性」中详细说明原因。

### 第三步：确认授权与期望信息

| 信息 | 说明 |
|---|---|
| 期望完成时间 | 必填 |
| 申请事由/变更说明 | 简述申请原因 |
| 授权项目名称 | 如 `One蛇口` |
| 授权应用 | 如 `cmsk_super_app` |
| 授权日期 | 授权有效期 |
| 抽数频率 | 如 `每日一次` |
| 抽数时间点 | 如 `无特别需求，入湖同学根据资源情况自行安排` |

### 第四步：生成 Excel 文档

使用 Python `openpyxl` 库，按以下步骤生成：

1. **复制模版样式**：从 `skills/入湖/数据入湖申请表模版.xlsx` 读取样式定义（字体、颜色、边框、对齐、列宽、行高、合并单元格）。
2. **填充数据入湖申请表单**：将确认的信息填入对应单元格。
3. **填充表结构说明模板**：为每张表生成字段级 DDL 说明。
4. **保留填写说明**：原样复制模版中的填写说明 Sheet。
5. **输出文件**：保存到 `skills/入湖/` 或用户指定路径，文件名为 `数据入湖申请表_<项目组>_<日期>.xlsx`。

## 样式规范

| 元素 | 样式 |
|---|---|
| 标题行（Row 1） | 深蓝底 `#003366`，白字，Microsoft YaHei 16pt 加粗，居中 |
| 区域标题（Row 3/8/16/29/34） | 蓝色底 `#0070C0`，白字，Microsoft YaHei 12pt 加粗，左对齐 |
| 标签列（A/C/E/G 等） | 浅蓝底 `#D9E1F2`，深灰字 `#333333`，Microsoft YaHei 11pt 加粗，右对齐 |
| 值列（B/D/F 等） | 无底色，深灰字 `#333333`，Microsoft YaHei 11pt，左对齐 |
| 表头行（Row 17） | 浅蓝底 `#D9E1F2`，深灰字，Microsoft YaHei 11pt 加粗，居中 |
| 数据行 | 无底色，深灰字，Microsoft YaHei 11pt，左对齐，自动换行 |
| 所有数据单元格 | 细线边框（thin），上下左右 |

## 禁止事项

- **禁止**编造不存在的表名、字段名、DDL。
- **禁止**在用户未确认信息前直接生成 Excel。
- **禁止**跳过必填字段（标【必填】的字段必须填写）。
- **禁止**默认使用全量同步——优先引导增量同步，全量同步需有明确理由。
- **禁止**修改模版文件 `数据入湖申请表模版.xlsx`。

## 完成标准

- 已确认所有必填申请信息（基础信息 + 来源库信息 + 表清单 + 授权信息）。
- 生成的 Excel 包含三个 Sheet，样式与模版一致。
- 数据入湖申请表单中所有必填字段已填写。
- 表结构说明模板中每张表都有完整的字段级说明。
- 填写说明 Sheet 完整保留。
- 文件已保存到指定路径。
- 未编造任何表名、字段名或 DDL。
